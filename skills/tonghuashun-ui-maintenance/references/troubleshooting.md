# 历史问题 → 最短恢复办法

保留已验证的恢复方法；历史股票、账户、日期和按钮编号不作为新任务输入。

日常保存确认先按 [本地文件协议](local-files.md)读取；本表只处理具体缺口或UI动作故障，不能把恢复扩大成全组盘点。

**先确定是局部控件、弹窗层级、连接还是窗口竞争问题。** 局部问题才按“观察 → 必要时重选左组/右股 → 已保存状态明确时只重开设置一次”恢复，不把所有错误都变成切窗口。

报错后先看是否实际生效，再重试。最多三次有新状态的尝试，不连点旧编号；重进一次仍失败则留回执、继续安全独立项。不要将单股故障变成全轮重做。

| 历史表现 | 原因/风险 | 恢复与防复发 |
|---|---|---|
| 独立分屏也找到分组设置，却不是用户指定主屏 | getApp附着应用，不保证主窗口；分屏也有同名控件 | 首次仅用实时窗口→主窗口一次，核对顶层主窗口身份；已在主窗口自选页直接用齿轮，未在自选页才06。不最大化、不挪屏、不改其它分屏 |
| 空标题/Unknown导致反复切主窗口 | 主窗口可为空标题，设置、添加、新建均可为Unknown | 用顶层ID、弹窗内容及来源链识别；添加页用完成回设置，新建页用本层取消/确定，不用窗口菜单或06跳过弹窗 |
| 小加号换位置或点错＋ | 标签增删/窗口缩放导致换行，新建和编辑混淆 | 找实名分组设置齿轮；旁边＋新建、表格＋、右侧＋自选、顶栏新页面＋各不相同 |
| -10005、noWindowsAvailable、windowNotFoundAtPosition，但仍可截图 | 可读截图不代表坐标转换/窗口点击可用 | 停止旧坐标，先观察并优先当前主窗口/弹窗AX。仅已确认主窗口的Raise可用于必要抬起；只读也失效才重附着一次。仍失败留断点，不调分辨率或杀进程 |
| native pipe closed before response | 动作可能已执行，响应连接才中断 | 先只读刷新一次；若已进入目标层直接继续。不能重复打开、重复添加或重跑入口；句柄真正失效才一次重附着 |
| The user changed，或前台又回看盘分屏 | 状态版本变化，也可能有用户/其它任务操作 | 刷新后仍在正确层就新定位；确实切屏且一次恢复后又被切走，停止本批并报告，不抢焦点 |
| 选过左组却删不动 | 左组选中丢失，或只有右股选中 | 重选左精确组并看selected，确认右侧加载，再选完整代码并再读选中；到尝试上限退出重进 |
| 删下一只误删相邻股 | 前次删除改变动态行/编号，沿用旧索引会误选 | 每只按代码重新定位，删前重读选中，删后对代码差集，不只看减1。非目标变化立即停批，按前证据只恢复本轮误改并核验，不用全局恢复掩盖 |
| 切组标题变了，右表仍上一组；出现假失败 | 异步加载、旧列表残留 | 补一次只读观察，仍不符才重选一次；不能无限刷新直到“看起来稳定”。不把旧组数据记到新组，不固定长睡眠 |
| 已加却在首屏找不到 | 虚拟列表/分页/显示上限，某些版本可能出现行数截断 | 先用本地文件确认目标；仅文件缺口时在目标组search remove局部核验。完整审计另获授权才读总数、分页去重，不把首屏当全量 |
| 滚动无进展，滚错左表 | 按第几个/最后一个滚动条猜，跨父容器匹配；换组也可能继承上一组底部位置 | 在真实左/右表父容器定位，未齐且起点未知先回该表顶部；每段看成员变化，无进展重定位，不盲扫 |
| AX已列完但总数差一，反复滚动仍不齐 | 解析器仅接受六位代码，漏掉指数等非A股成员 | 对照原始右表文本，保留真实代码格式及名称；界面总数包含全部标的，A股涨停数另与上游全集求交集 |
| 输代码没刷新，或同代码匹配到问AI/期权 | 空白框、失焦、旧结果或代码文字重复 | 找占位文字框；setValue已成功就不多做输入。精确证券代码/名称/市场与同一行add/remove一起核验，跳转选股行不是证券；未刷新才聚焦重输 |
| 连续添加索引失效，已有股反被删 | 每次结果换编号，同位置add/remove状态切换；问AI建议可能在证券结果之后异步扩展 | 新结果新定位；add才加、remove只读。报错先读实际代码行与状态，已remove直接记成功，仍add才用新索引重试单步；输入值正确时不重输代码、不重跑整批 |
| 中断后变量/函数不存在或split类型错误 | 脚本状态丢失、字符串/对象用错 | 先只读取当前AX，核对返回类型并重建变量；不因此切屏/重置应用。先分辨主页/设置/添加/确认层再补剩余 |
| 点完成但未保存；取消后改动仍在 | 内层完成≠外层保存，部分操作实时生效 | 完成→外层确定→本地文件确认；只有文件缺口才局部重进，不假设全回滚，不凭点击报成功 |
| 左右箭头同名，误当上移一行 | 同名不同对象 | 分组用左、股票用右；⬆︎直接置顶，全序逆序执行；主页AX拼接顺序不作证明 |
| 用户中途操作或锁屏 | 页面改变，旧状态失效 | 新输入重读，锁屏不猜点，留已完成回执；解锁定位后继续差集，不重复研究或整批 |

误改恢复只针对有操作前证据、能归因于本轮的差异；用户同时改动且无法区分时停止该项并报告，不用旧整组快照覆盖用户新数据。恢复失败单列优先处理，不能报整体成功。
