# Computer Use 接入：只转换工具，不改变操作规则

页面和按钮语义不依赖模型名称、聊天记录或固定机器路径。另一AI必须能用Computer Use控制用户这台Mac上的同花顺、读取当前界面；只有网页浏览器、无桌面权限的环境不能执行。其它操作系统/客户端版本先核对结构，不套坐标。

## 只接入一次

1. 阅读当前Computer Use工具说明，确定附着应用、观察、点击、输入、滚动的方法。
2. 将主手册动作映射到当前工具。语义/无障碍控件优先；只有截图工具时用当前截图定位。
3. 一次只由一个操作者控制同花顺。应用句柄并不把macOS操作固定在某个物理屏幕/窗口；每次动作依据当前顶层身份和已确认的弹窗来源。发现切窗换组先观察，不抢回一串旧动作，不操作其它看盘分屏。

## CUA工具适配示例

以下示例使用 `mcp__cua_repl.js` 接口；工具由运行环境提供，本仓库不包含运行时。先阅读当前工具文档，仅在接口匹配时使用。首调用或重置后只执行一次入口调用，并先读返回文档：

```javascript
var thsApp = await cua.getApp("同花顺");
```

getApp可能首先返回正在前台的独立分屏，不能马上点击其中的同名齿轮。按主手册只进入主窗口一次，之后复用句柄；不逐股重新getApp。名称不匹配才用当次文档的应用清单找到确切应用。不硬编码导入包、PID、bundle ID或远程地址，也不假定存在按窗口ID绑定的macOS API。

后续模式（编号从最近状态重新定位，示例不提供固定编号）：

```javascript
var thsAx = await thsApp.getAXState({emit:false, disableDiffing:true});
if (typeof thsAx !== "string") throw new Error("未取得可解析的当前AX文本");
// 在完整thsAx内核对顶层身份、父容器及唯一控件。
// 当前没有目标控件时先识别弹窗层级，不猜编号/坐标。
// 从本次thsAx解析出currentIndex后，才执行：
await thsApp.click(currentIndex);
thsAx = await thsApp.getAXState({emit:false, disableDiffing:true});
// 只输出当前所需容器/选中行/结果摘要，不反复输出全部行情树。
```

- `getAXState()` 返回字符串，按行处理，不当成对象或元素数组。程序要完整父子结构/列表时取 `disableDiffing:true`；默认差分只说明变化，未出现某行不能证明其不存在。读取完整树可emit:false并输出局部摘要，兼顾正确定位与上下文开销。
- `getAXStateAndScreenshot({emit:false})` 返回 `{state,screenshot}`；截图用 `nodeRepl.emitImage(result.screenshot)`，不要对整个对象split。只截图后要重新取得完整AX才能用元素索引。
- 写可复用操作函数时共享一个明确的最新状态对象，每次观察更新同一对象；不要让闭包保留旧AX字符串，或在不同调用里重声明同名变量却误以为所有函数已引用新状态。局部索引失效只刷新本层，不据此切主窗口。
- 点击：`thsApp.click(index)`；当前截图坐标 `thsApp.click([x,y])`；右键 `thsApp.click(index,{mouseButton:'right'})`。遵守工具坐标系，不自行乘缩放比。仅截图中的主窗口/已确认弹窗可用坐标，不拿整个桌面另一屏的位置重试。
- 输入：优先对有占位文字的框调用一次 `thsApp.setValue(index,code)` 并观察。值与结果已更新就继续，不追加键盘动作。仅未触发搜索时才重新定位该框、聚焦、核对焦点后全选并输入；每个动作后观察。不能在股票表全选后删除，也不能把整串代码转成数字而丢前导零。
- 默认点精确结果行的 `search add`。历史有版本支持回车加入；仅该版本已验证、精确目标行选中、结果为add时才可一次 `pressKey('Return')`，不拿回车试探未知状态。
- 滚动：`thsApp.scroll(currentScrollAreaIndex,'down',1)` 后观察。只有数量未齐才滚；父容器与左右表对应，不能跳底就算读完。AX已列全且唯一数量吻合时不额外滚动。
- 只有已确认的主窗口/其弹窗暴露 `Secondary Actions: Raise` 且确实需要抬起时，才调用相应动作；不能抬起初始附着的独立分屏来“恢复”。不反复Raise，不猜未暴露动作。
- `mcp__cua_repl.js_reset` 仅在会话不可用时使用，不作为普通卡顿/索引错误的首选；它不关闭客户端。重置后按首调用规则重新附着、读取当前层级，重建变量/辅助函数，先恢复上下文再计算未完成差集。
- 变量/函数未定义、AX类型错误是脚本状态问题：先取当前UI重建所需变量，不能据此认为窗口错误并切屏。示例变量名/编号均不是下次可直接复用的状态。

## 优先加载已有操作函数

本技能已提供 `scripts/ui_ops.mjs`。按 [操作函数](operation-functions.md) 加载一次并传入当前app对象和本地快照；分类、连板、排序复用同一控制器。它保留当前状态并逐步刷新编号，修复旧临时代码的北交所判断与延迟时反向点击问题；保存后统一接 `saveBatch → local_groups.py verify → confirmSaved`。模块代码保存在磁盘、每次重新取得当前状态，不保存旧截图或元素编号。不要用旧临时函数覆盖新的状态和保存确认流程。

## 连接错误不重放动作

`Sky Computer Use native pipe closed before response` 等报错可能发生在动作已执行之后。先用现有句柄只读取得一次最新AX：若已进入添加页，直接继续添加页；若原页未变，再按新索引重试该单步。仅观察也持续失败或句柄无效时才重新附着一次，并重新确认主窗口及弹窗来源；仍失败则留断点，不关闭窗口、不重启/清理服务、不重放整组。

`The user changed ... Re-query ...` 先只读刷新。若仍是正确主窗口/同一弹窗，只更新索引；若真正转到分屏，按主手册的窗口竞争规则停下，不能当作允许反复切回主窗口的信号。

只提供旧版node_repl＋sky或其它API时，读它当次公开文档再映射相同语义。不要为了复用示例绕过当前插件、装隐藏依赖或直接改同花顺配置/数据库。文本处理可辅助去重、差集、回执；实际修改只走UI。

## 省时观察

首次需要操作时观察一次当前窗口与控件结构；正常步骤仅输出所需容器、选中对象、目标代码及按钮状态。分组目录、成员、差集及保存后确认走local-files.md，不借首次观察再做全量盘点。完整状态可留在本次会话解析，不必反复灌入模型。

不能用跨容器宽泛正则推断选中组，例如任意row(selected)后若干字符有组名就算通过。按真实父子关系或截图分别验证左组、右股。查找组名按字面匹配/转义，避免点号、加号、括号被当正则语法。

工具返回success、没有异常或动作耗时很久均不是最终成功；动作后和保存后的界面才是证据。报错也可能已生效，先观察再重试。
