# 同花顺 UI 分组维护

[English](README.en.md) · [技能正文](SKILL.md) · [MIT License](LICENSE)

面向macOS同花顺客户端的AI桌面操作技能：读取和维护自选分组、添加/移除/移动成员、按指定顺序或当日涨停数量排序，并在保存后回读核验。

这是可供AI运行环境加载的操作说明与少量离线辅助工具。桌面控制能力由运行环境提供，本仓库不包含同花顺客户端、Computer Use运行时或行情服务。

## 适用场景

- 只读取得精确组名、顺序和完整成员。
- 按用户给定名单加入、移除或移动股票，避免重复加入和误删。
- 保留多个已明确指定的目标组，全部目标核验成功后再移除错误源组。
- 在主窗口及其分组弹窗内工作，保留其他看盘分屏的位置和布局。
- 从连接中断、动态索引变化、Unknown弹窗或异步搜索结果恢复。
- 根据完整的最终涨停事实排序，不将平均涨幅或主观判断冒充数量排序。

## 使用条件

需要macOS、同花顺客户端，以及能观察和操作该电脑桌面的AI工具。按该工具要求配置辅助功能/屏幕录制权限。仅有网页搜索或云端代码执行器的环境不能操作本机同花顺。

本技能不绑定某个模型。先阅读运行环境当前工具文档，再将语义动作映射到它；`references/computer-use.md`包含一种CUA接口的适配示例，不保证其他版本接口完全相同。

## 安装

1. 下载本仓库，或克隆到一个新的目录：

   ```bash
   git clone https://github.com/huang15807602345-tech/tonghuashun-ui-maintenance.git
   ```

2. 在支持Agent Skills的运行环境中加载此目录的`SKILL.md`，或将整个目录安装到该环境支持的技能目录。Codex本地用户技能目录可使用`~/.codex/skills/tonghuashun-ui-maintenance/`；目录中已存在个人版本时先比较和备份，不覆盖个人规则。
3. 首次请求只读盘点，确认目标主窗口和精确组名后，再执行明确授权的变更。

## 请求示例

```text
使用 $tonghuashun-ui-maintenance，只读列出当前全部自选分组名称、顺序和界面总数。
保留其他看盘窗口的布局，不修改成员。
```

```text
使用 $tonghuashun-ui-maintenance，按我提供的股票代码和目标组执行加入。
已经存在的只核验；按组保存后重新打开验证，报告实际结果。
```

移动、多目标加入、删除或排序时明确给出精确目标及范围。清空/删组需明确请求；普通分类不能推导清空权限。股票代码始终用字符串，保留前导零。

## 离线排序辅助

需要Python 3.10或以上，无第三方Python依赖：

```bash
python3 scripts/plan_group_order.py --input examples/sorting-input.json
python3 -m unittest discover -s tests -v
python3 scripts/validate_package.py
```

输入中的股票代码与组名为合成示例，不对应维护者的持仓或真实自选目录。调用方必须自己核验交易日、最终名单、风险警示过滤和实时完整成员。脚本只计算计划，实际修改仍由AI通过UI执行。

## 核验与已知限制

- 操作方法来自实际桌面工作流的迭代，首次公开版本不声明所有模型、macOS或客户端版本均已实测。
- 自动测试覆盖离线排序和包结构，不构成真实客户端写入成功的证据。
- 动态界面必须每次重新观察；连接报错后动作也可能已经生效，应先核对现状。
- 外层保存后重新打开，逐码/逐组回读，才能报告完成。失败项单列，支持按剩余差集续作。
- 不读取交易账户，不买卖、撤单或转账，不修改客户端配置数据库，不包含自动涨停原因研究。
